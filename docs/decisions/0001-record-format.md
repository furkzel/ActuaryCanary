# 0001 — Decision record format

## Context
Choices need to be understandable years later without asking the person who made them.

## Decision
Each significant choice gets one short numbered file in `docs/decisions/` with three parts: context, decision, consequences. A record stays under 30 lines. Records are never edited after merge; a changed choice is a new record that names the one it supersedes.

## Consequences
- The folder is a readable history of the project.
- Small corrections (typos) are allowed; changes of meaning are not.
