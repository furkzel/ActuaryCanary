## Finding for the owner
A column can rest on one finite link ratio and still sum three origins: zero-denominator cells add to the numerator only (PROPERTY paid 12-24 on the tiny baseline). The rule counts the link ratios that exist (the number the stability table shows), so it replaced an average of 4.459 that `ZERO_DENOMINATOR` already flagged. That is what the rule says; the alternative reading (count the origins of the usable set) would leave that factor to the register. Nothing on the demo depends on it.
