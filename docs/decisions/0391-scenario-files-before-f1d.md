# 0391 — Scenario files before F1d

## Context
F1d changes the generator in two places (premium movements, nil-closing reserve). To show which files moved and why, every file of every scenario at size tiny was hashed first, on `main` as of A1a (`8e129c2`), with `just synth all tiny`.

## Decision
The list below is the reference: `<scenario>/tiny/<path> <first 16 hex digits of SHA-256>`. Records 0392 and 0395 compare against it.

## Consequences
- 512 files in 9 scenarios. The generator is deterministic for a seed, so a second run reproduces the hashes unless a change moves them.
