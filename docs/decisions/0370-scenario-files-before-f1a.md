# 0370 — Scenario files before F1a

## Context
Item F1a changes the generator. Which scenario files must not move is checked against a reference taken before the first change. Taken on commit 039b90c (main after CI1) with `uv run python -m actuarycanary.synthetic write all tiny --out <folder>`, written twice with identical hashes (the output is deterministic on this machine).

## Decision
Reference: SHA-256, first 16 hex digits, of every file of every scenario at size tiny (440 files, 8 scenarios). Path is relative to the scenario-folders folder. Stage 4 writes the same set again and lists every file that moved in record 0376. The hashes hold for the Python 3.12, polars, pyarrow and xlsxwriter versions of `uv.lock` at this commit and only on the machine class that wrote them.

## Consequences
- A file whose hash differs after F1a needs a cause named in 0376; a file with no named cause is a stop-and-ask.
