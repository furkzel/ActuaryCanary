# 0380 — Scenario files before F1bc

## Context
Item F1bc moves four feeds (reinsurance treaties, reinsurance transactions, recoveries, ledger) out of the subfolder `phase2/` of the generated scenarios and touches the generator for nothing else. Which scenario files must not move is checked against a reference taken before the first change. Taken on commit 4fb9570 (main after F1a) with `just synth all tiny`.

## Decision
Reference: SHA-256, first 16 hex digits, of every file of every scenario at size tiny (513 files, 9 scenarios: the eight of 0370 and `messy_incremental`). Path is relative to the scenario-folders folder, the size folder `tiny/` left out. Stage 3 writes the same set again and lists every file that moved in record 0383. The hashes hold for the Python 3.12, polars, pyarrow and xlsxwriter versions of `uv.lock` at that commit.

## Consequences
- A file whose hash differs after stage 3 needs a cause named in 0383; a file with no named cause is a stop-and-ask.
